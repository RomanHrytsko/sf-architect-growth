# sf-architect-growth

Приватний навчальний репозиторій: 12-місячний шлях Senior Salesforce Developer до рівня Salesforce Architect (старт 9 листопада 2026). Формат: практика, ADR та ревʼю замість конспектів.

## Де що лежить

| Папка | Для чого |
| --- | --- |
| `plan/` | `ROADMAP.md` (актуальний план і статус), `CHANGELOG.md` |
| `journal/` | Тижневі записи `YYYY-Www.md`, `scorecard.md` з оцінками PR |
| `adr/` | Architecture Decision Records (шаблон `0000-template.md`) |
| `katas/` | Вправи на патерни з рефакторингом |
| `notes/` | Конспекти своїми словами по треках |
| `reviews/` | Mock design-review у форматі review board |
| `diagrams/` | C4, sequence, потоки даних |

## Ритм

4 години на тиждень (Learn 1 · Practice 1,5 · Design 0,5 · Review 1) і сесія з ментором щосуботи. Гілки `wNN/<тема>`, невеликі PR за шаблоном із `.github/`.

## Портфоліо

Проєкти RenewalHub, IntegrationHub і Renewal Agents живуть в окремих репозиторіях і стають публічними, коли готові. Цей репозиторій лишається приватним.

Контекст для ментора: `CLAUDE.md`.
